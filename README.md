# PolyAVP Website

Single-page marketing site for PolyAVP: Introduction, Services (Technical / Marketing) and Work & Reviews.

Plain HTML, CSS and JavaScript. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

    python -m http.server 8080
